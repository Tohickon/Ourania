Bottom line: Ourania has an exceptionally deep computational engine (~35 astro classes), an enormous interpretation corpus (~75 MB of prose across 59 data files), and an impressively rigorous test suite (170K+ checks). Its core strengths — natal calculation, aspects (including minors), dignity/sect, synastry, composites, progressions, solar arcs, profections, zodiacal releasing, and narrative synthesis — put it in the same functional tier as TimePassages.

The 94 missing items cluster around three themes:

Professional workflow tools — export (PDF/image/print), chart database, rectification, astrocartography, multi-chart workspace
Specialized techniques — eclipses, declinations, fixed stars, sidereal zodiac, horary/electional
Engineering maturity — build system, installer, CI/CD, file decomposition, accessibility
The app is roughly 60% complete for a consumer-grade astrology desktop application and 40% complete for a Solar Fire-class professional tool.
